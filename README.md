# 📅 Pronote to Apple Calendar Sync

Synchronisation automatique, sécurisée et sans risque de l'emploi du temps Pronote vers Apple Calendrier (iOS & macOS).

## ✨ Fonctionnalités
- 🔄 **Synchronisation automatique** : 3 fois par jour via GitHub Actions (0 requête superflue, aucun risque de surcharge).
- ❌ **Gestion des absences & annulations** : Marque directement `❌ [ANNULÉ]` avec le motif (Prof. absent, Cours annulé).
- 📍 **Détails complets** : Salles, professeurs, groupes et remarques.
- 🔒 **Sécurité maximale** : Authentification par jeton officiel de l'application mobile (aucun mot de passe stocké).
